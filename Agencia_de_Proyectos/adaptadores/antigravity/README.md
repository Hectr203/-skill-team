# Google Antigravity

Coloca una copia o referencia aprobada de `AGENTS.md` en el workspace, skills
como `SKILL.md` con frontmatter `name` y `description`, reglas en `rules/` y MCP
en la configuración propia de Antigravity. `agy`, `.agents/` y `~/.gemini/config`
dependen de la instalación; no se afirma compatibilidad runtime sin probarla.
El navegador integrado tiene precedencia sobre Playwright MCP.
