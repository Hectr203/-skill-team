# Como empezar

## Proyecto nuevo

Crear `contexts/projects/<id>/`, completar `plantillas/manifiesto-proyecto.md`,
indicar usuario, problema y criterios. Ejecutar el flujo nuevo. Solo luego de
crear frontend/backend base pedir indexación Graphify.

## Proyecto existente

Indicar ruta y cambios ajenos. Recuperar memoria, comprobar grafo o indexarlo,
reproducir el estado actual y escoger el mínimo cambio compatible.

## Auditoria

Solicitar `auditoria` para generar reportes y planes. No se remedia código hasta
la aprobación de los planes.

## Diseño, SEO, CRM o redes

Activar el agente especializado y el skill correspondiente. Los entregables son
borradores o análisis hasta que el humano autorice acciones externas.
