# Catalogo funcional

## Ingeniería de Software
- **Core Stacks y Arquitectura**: Ponytail, React, Redux Toolkit / Zustand, Atomic Design, Clean Architecture, Node/Express, Prisma / PostgreSQL, APIs REST y GraphQL.
- **Suite de Ingeniería de Google / Addy Osmani (`agent-skills`)**: 23 skills de clase mundial cubriendo diseño de APIs, DevTools, CI/CD, revisión de código, simplificación, ingeniería de contexto, debugging, deprecación, ADRs, TDD, SDD, performance, planificación y lanzamiento.
- **Preservación Brownfield**: Conservación de estructura actual, lectura y diagnóstico de arquitectura existente, refactorización controlada y adaptación de repositorios.
- **Despliegue Multi-Cloud**: Despliegue en Azure con Azure CLI (proyecto nuevo y existente) y pipelines CI/CD.

## Contexto, Memoria y Auditoría
- **Suite de Contexto y Tokens**: Graphify (grafos de código), claude-mem (memoria persistente universal), Headroom (compresión semántica) y ahorro-contexto con scripts locales de memoria de proyecto (`arranque.py`, `cierre.py`, `memoria_proyecto.py`).
- **Auditoría Técnica y Calidad**: `improve` (Codebase Advisor senior, solo lectura en 9 categorías y emisión de planes en `plans/`) y `mejora-asesor` (orquestación bi-modelo inteligente/económico).
- **Cacería de Vulnerabilidades**: `security-audit` de Cloudflare (ledger determinista, refutación independiente y matrices de ataque especializadas).

## Diseño Visual y Motion Engineering
- **Google Stitch**: Prototipado y generación rápida *design-to-code* con design tokens.
- **Apple Design & Emil Kowalski**: Directivas visuales de élite, microinteracciones interrumpibles y física elástica.
- **Anime.js Motion**: Timelines ligeros, morphing SVG y control reactivo sin dependencias pesadas.
- **React Bits**: Catálogo de componentes interactivos y animaciones de producción.
- **UI/UX Pro Max**: Suite completa de razonamiento de diseño, 12 bases de datos CSV (paletas, tipografía, stacks, landing, charts, accesibilidad) y scripts de generación de sistemas de diseño (`design_system.py`, `search.py`).

## Automatización Web, Testing y Notificaciones
- **Testing Web E2E**: Fallback prioritario (navegador integrado de Google Antigravity IDE $\rightarrow$ Playwright MCP) y suite completa de testing (`playwright-mcp-testing`).
- **Notificaciones y Human-in-the-Loop**: Scripts locales y skill `notificacion-finalizacion` (`notificar_tarea.py`, `solicitar_autorizacion.py`, `solicitar_validacion.py`) para avisos visuales y audibles al culminar tareas o requerir compuertas humanas.

## Negocio, Marketing y Posicionamiento
- **Claude SEO**: Auditorías técnicas falsables, Schema.org JSON-LD, Core Web Vitals y optimización para motores de IA (GEO/AEO).
- **Auto-CRM**: Módulo comercial 100% privado en SQLite, captura de prospectos vía webhooks y pipeline visual.
- **Social Media Skills**: 17 habilidades de contenido, protocolo `voice-builder` para aislamiento de tono de voz, LinkedIn y guiones audiovisuales.
