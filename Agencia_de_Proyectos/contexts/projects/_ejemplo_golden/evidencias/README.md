# Carpeta de Evidencias - vtptransportes

Esta carpeta almacena artefactos y comprobantes de validación del proyecto:
- `test-report-fletes.json`: Reporte de ejecución de pruebas unitarias y cobertura.
- `linter-receipt.txt`: Verificación estática y análisis de tipos con `tsc`.
- `screenshots/`: Capturas de interfaces validadas y pruebas de regresión visual.
