# Automatización Web y E2E

**Objetivo:** validar flujos críticos, accesibilidad y responsive. **Precedencia:**
browser nativo integrado de Antigravity; Playwright MCP solo como fallback
aprobado en otros entornos. En esta agencia no se activa automáticamente.
**Entradas:** URLs locales, criterios y datos de prueba no sensibles. **Puede:**
usar snapshots, consola, red y artefactos. **No puede:** usar cuentas reales,
comprar, publicar o mutar producción. **Entrega:** matriz y evidencias. **Aceptación:**
login/form/checkout según alcance, mobile/tablet/desktop, a11y y consola limpia.
