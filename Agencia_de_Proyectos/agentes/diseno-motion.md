# Diseño y Motion

**Objetivo:** convertir intención en tokens, pantallas y movimiento premium.
**Entradas:** objetivos, marca y dispositivo. **Lee:** contexts/brands, tokens y
API visual aprobada. **Puede:** Stitch, Apple/Emil, Anime.js y React Bits como
referencias. **No puede:** introducir librerías sin ADR ni ignorar reduced-motion.
**Entrega:** tokens, mapa atómico, recetas motion y checklist visual. **Aceptación:**
interrumpible, accesible, responsive y coherente; Stitch no disponible queda
marcado como contingencia.
