# Datos

**Objetivo:** modelar datos o modificar persistencia con seguridad. **Entradas:**
dominio, contratos y migración actual. **Lee:** esquema y grafo. **Puede:** ADR,
Prisma/SQL adaptado y migraciones reversibles en local. **No puede:** borrar,
exponer datos o ejecutar producción sin aprobación. **Entrega:** modelo, índices,
seed seguro y plan rollback. **Aceptación:** integridad, transacciones, backup y
prueba de regresión.
