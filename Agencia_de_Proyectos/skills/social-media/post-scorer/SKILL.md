# Puntuación Previa de Publicaciones (Post Scorer)

Basado en la herramienta de evaluación de **Social Media Skills** ([github.com/charlie947/social-media-skills](https://github.com/charlie947/social-media-skills)). Califica objetivamente cualquier borrador antes de presentarlo al usuario para aprobación.

## Matriz de Puntuación (Escala 0 - 100)

1. **Eficacia del Gancho (0 - 30 pts)**:
   - ¿Genera curiosidad irresistible?
   - ¿Queda visible antes del botón "...ver más"?
   - ¿Evita frases gastadas o introducciones lentas?
2. **Legibilidad y Formato Móvil (0 - 25 pts)**:
   - Párrafos de máximo 2 líneas.
   - Espacio en blanco adecuado para descansar la vista.
   - Uso medido y coherente de negritas o emojis según la voz de marca.
3. **Calidad del Valor Aportado (0 - 25 pts)**:
   - ¿Enseña algo nuevo o refuta un mito común?
   - ¿Tiene aplicación práctica inmediata?
4. **Fuerza del Cierre y Llamada a la Acción (0 - 20 pts)**:
   - ¿Invita a una conversación auténtica sin sonar desesperado?

## Umbral de Aprobación
- Un post requiere un puntaje mínimo de **75/100** para ser propuesto.
- Si obtiene menos de 75, el agente debe reescribir el gancho o sintetizar el cuerpo antes de solicitar la revisión humana.
