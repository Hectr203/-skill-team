## Reglas de memoria
- La memoria del proyecto vive en `.memoria/`.
- El arranque se hace con `--proyecto proyectos/<nombre>`.
- El cierre se registra con `--proyecto proyectos/<nombre>`.
- No se comparte memoria con otros proyectos.
