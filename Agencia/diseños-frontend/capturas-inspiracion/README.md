# Capturas de Inspiración

Coloca aquí las imágenes, screenshots o referencias visuales del diseño que quieres replicar.

## Cómo agregar capturas

1. Guarda la imagen en esta carpeta con un nombre descriptivo:
   - `dashboard-principal.png`
   - `login-dark.png`
   - `tabla-conductores-mobile.png`

2. Documenta qué parte del proyecto usa esa captura en `componentes-ui/componentes.md` o en `efectos-y-animaciones/efectos.md` referenciando el archivo.

## Convenciones de nombre

| Prefijo | Uso |
|---|---|
| `pantalla-` | Vista completa de una pantalla |
| `componente-` | Captura de un componente específico |
| `efecto-` | GIF o imagen mostrando un efecto o animación |
| `movil-` | Versión móvil / responsiva |
| `dark-` | Versión en modo oscuro |
