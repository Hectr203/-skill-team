# Componentes UI de Referencia

Documenta aquí cómo deben verse los componentes clave. El agente los replicará al construir la interfaz.

## Formato

```
### [Nombre del componente]
- **Tipo**: (botón / input / card / tabla / modal / navbar / sidebar / badge / etc.)
- **Captura**: capturas-inspiracion/nombre-archivo.png (si tienes una imagen)
- **Descripción visual**: Describe colores, bordes, tamaños, estado hover/focus
- **Clases Tailwind sugeridas**: (opcional)
- **Variantes**: (primary / secondary / danger / ghost / outline / etc.)
```

## Componentes del Proyecto

<!-- Define tus componentes aquí -->

### Botones
- **Tipo**: button
- **Descripción visual**: Bordes redondeados (`rounded-lg`), sin sombra por defecto, sombra suave al hover.
- **Variantes a definir**: Primary, Secondary, Danger, Ghost

### Cards / Tarjetas
- **Tipo**: card
- **Descripción visual**: Fondo blanco / gris oscuro en dark mode, borde suave, padding generoso.

### Formularios / Inputs
- **Tipo**: input
- **Descripción visual**: Borde gris claro, focus con anillo de color primario, label flotante o arriba.

### Tablas de Datos
- **Tipo**: table
- **Descripción visual**: Cabecera con fondo suave, filas alternas, hover en fila.

### Navegación (Navbar / Sidebar)
- **Tipo**: nav
- **Descripción visual**: —

### Modales / Diálogos
- **Tipo**: modal
- **Descripción visual**: Overlay oscuro semitransparente, card centrada, animación de entrada.
