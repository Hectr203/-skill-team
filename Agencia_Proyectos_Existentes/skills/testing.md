# Skill: Testing

## Proposito
Definir o ejecutar validaciones proporcionales al riesgo.

## Base principal
- `Agencia_Proyectos_Existentes/skills/agent-skills/skills/test-driven-development/SKILL.md`
- `Agencia_Proyectos_Existentes/skills/agent-skills/agents/test-engineer.md`

## Rol en el sistema
Esta skill local cubre el trabajo de pruebas del proyecto y aterriza el enfoque TDD/prove-it del nucleo sobre el codigo real que se este cambiando.

## Cuando usar
- Bugs.
- Nueva funcionalidad.
- Refactorizaciones.
- Flujos criticos.

## Procedimiento
1. Identificar comportamiento esperado.
2. Elegir nivel de prueba: unitario, integracion, E2E o manual.
3. Cubrir camino feliz, errores y bordes.
4. Ejecutar o documentar pruebas pendientes.

## Salidas
- Casos de prueba.
- Resultado de validacion.
- Brechas de cobertura.
