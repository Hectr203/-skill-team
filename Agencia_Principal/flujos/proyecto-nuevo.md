# Proyecto nuevo

El [asistente principal](../asistente-principal.md) coordina este flujo. Aplicar [precedencia](../reglas/precedencia.md), [contrato de roles](../agentes/contrato-agente.md) y [selección de skills](../reglas/seleccion-skills.md). Tecnología y arquitectura se resuelven en el perfil del manifiesto.

## Activación
Una iniciativa sin código existente necesita bases de desarrollo.

## Entradas
Objetivo, alcance, criterios, ID y restricciones.

## Procedimiento
Elegir el perfil documentado; usar el estándar solo si no se acordó otro. Registrar contexto mediante CLI o MCP; definir ubicación del código fuera de la agencia. Acordar contratos y responsabilidades de las capas necesarias, sin exigir todas. Preparar andamiaje con herramientas/versiones pertinentes, respetando archivos existentes. Configurar pruebas y CI solo según necesidades reales. Despliegue se prepara por separado, sin crear recursos.

## Entrega
Base ejecutable pertinente, manifiesto y decisiones consistentes, controles y pendientes.

## Criterios de aceptación
La base satisface criterios de inicio y existe evidencia de ejecución; preparación no equivale a despliegue.
