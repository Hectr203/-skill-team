# Adaptador de despliegue Azure

El [asistente principal](../asistente-principal.md) coordina este flujo. Aplicar [precedencia](../reglas/precedencia.md), [contrato de roles](../agentes/contrato-agente.md) y [selección de skills](../reglas/seleccion-skills.md). Tecnología y arquitectura se resuelven en el perfil del manifiesto.

## Activación
El usuario selecciona Azure para el proyecto; no es un requisito universal.

## Entradas
Perfil real, entorno, región, presupuesto, permisos, riesgos y artefactos comprobados.

## Procedimiento
Diseñar servicios según requisitos sin crear recursos. Preparar configuración, secretos referenciados y operación reproducible. Confirmar autorización vigente para costos, red, datos y publicación. Ejecutar por dependencias reales con herramientas disponibles, verificando resultados y criterios de rollback. Documentar operaciones y datos redactados; no forzar lenguaje o librerías del estándar.

## Entrega
Diseño o despliegue identificado, recursos reales, pruebas y recuperación.

## Criterios de aceptación
La entrega cumple la fase autorizada y distingue preparación, operación y controles externos pendientes.
