# Roles y skills

El [asistente principal](../asistente-principal.md) coordina; el [contrato común](../agentes/contrato-agente.md) define entradas, límites y traspasos. El [registro de roles](../reglas/rutas-agentes.json) identifica fichas, sin asignarles tecnologías o un conjunto cerrado de skills.

Todos los roles descubren habilidades mediante [selección por tarea](../reglas/seleccion-skills.md), usando CLI o MCP. Leer fuentes y comprobar compatibilidad antes de aplicar. Nuevos roles se crean desde [plantilla](../plantillas/nuevo-agente.md), se registran y reutilizan el mismo mecanismo sin duplicarlo.
