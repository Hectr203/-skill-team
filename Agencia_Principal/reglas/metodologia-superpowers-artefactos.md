# Metodología y planes de trabajo

La agencia adapta análisis, planificación, implementación y verificación al alcance y riesgo. No presupone una skill global, proveedor de IA, IDE o metodología instalada. Una integración metodológica, incluida Superpowers, es opcional y se selecciona mediante [skills](seleccion-skills.md).

Presentar el plan en el chat o artefacto disponible. Guardar decisiones estables, especificaciones y evidencias en la ubicación acordada del proyecto cuando aporte trazabilidad. No inventar directorios internos de otro IDE ni acumular copias temporales; tampoco prohibir documentación útil por su nombre de carpeta.

TDD puede emplearse para cambios de comportamiento o reproducción de defectos; usar controles pertinentes y conservar código válido. Las autorizaciones vigentes cubren el alcance acordado; preguntar solo por información o permisos indispensables que faltan. La delegación sigue el [asistente principal](../asistente-principal.md), sin fan-out obligatorio.

El cierre demuestra criterios con [evidencia](verificacion-local.md); no depende de una marca de herramienta. Esta ruta se conserva para compatibilidad con documentos anteriores.
