# Headroom
Opt-in, local-first Apache-2.0 tool. Use `headroom proxy`, `headroom wrap`, SDK or the documented MCP only after approval. Measure savings; never promise a fixed percentage. Keep fatal lines, stack traces and security evidence. Do not run installation in this agency task.
